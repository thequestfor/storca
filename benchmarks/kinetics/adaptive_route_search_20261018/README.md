# Adaptive route-search evaluation protocol

Status: **proposal only; native execution not authorized**. This panel evaluates
time to a verified mapped route, not rates, experimental agreement or stability.

Use three arms with the same electronic settings, final validators, fragment
evidence, allowed conformer information and total budgets:

- A: existing placement and fixed sequence, with the corrected shared
  endpoint-reference interpretation.
- B: improved paired geometry and a fixed sequence.
- C: improved paired geometry and the adaptive sequence.

Do not use the old scientifically unsupported encounter-to-asymptote inference
as an advantage or disadvantage for one arm. Freeze arm drivers and sources
before native execution; the separate B-arm wrapper remains to be prepared.

Proposed ordered cases:

1. H + CH4 -> H2 + CH3, using the already frozen mapped reaction and assumptions.
2. OH + H2 -> H2O + H, using existing preparation; obtain separate authorization.
3. H + ethene -> ethyl radical, with explicit complete nuclear maps and a
   declared doublet surface frozen before execution.
4. Cyclobutene -> butadiene, with declared mapping and stereochemistry frozen
   before execution. Retain the legitimate strained-ring identity checks.

H + methane is development, not a blind transfer test. Retained OH/methane
paths may test offline reader compatibility but are not new angular campaigns.
Reference TSs used to score held-out cases must not also enter their seed pool.
No experimental rate or barrier is supplied to predictions.

Success requires a meaningful first-order saddle, mapped reactive mode, both
IRC branches and independently validated actual reached species. A multistep
success requires all elementary segments and a coherent validated intermediate
chain. Barrierless candidates remain separately unresolved until an applicable
specialist method is supported.

Report all assigned cases, including failures/timeouts: verified-route yield
versus cumulative wall/core time and gradient calls; time to first fully
verified route; failed native attempts; reuse/continuation; preparation overhead;
and distinct approaches lost to filtering. False success claims must be zero.
No QZ energy or Arkane job is needed just to evaluate preparation/search.

Before launching this panel, derive explicit category and cumulative budgets
from the actual stage costs, freeze the new reaction maps/states/environments,
prepare the three arm drivers and obtain separate compute authorization.
There is no inherited free budget or unlimited search permission in this file.
A small pilot cannot establish global optimality or universal route coverage.
